# 📋 Excel Avançado + Power Query — Modelo Operacional

> Script Python que replica e documenta a lógica de transformação feita via Power Query no Excel — demonstrando domínio de ETL, fórmulas avançadas e geração de planilhas formatadas profissionalmente.

## Abas geradas no .xlsx
| Aba | Conteúdo |
|---|---|
| Resumo Executivo | Faturamento por categoria × mês com totais |
| CMV & Margem | Semáforo de rentabilidade por categoria |
| Ruptura de Estoque | % ruptura com alertas visuais (verde/amarelo/vermelho) |
| Power Query — Lógica | Documentação das 12 etapas de transformação em linguagem M |

## Como executar
```bash
pip install pandas openpyxl numpy
python modelo_excel_avancado.py
```
